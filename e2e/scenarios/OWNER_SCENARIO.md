# オーナー目線 E2Eシナリオ

## シナリオ概要
オンラインショップのオーナーが、サイト登録から商品登録、日常的な業務フローを実行するシナリオ。

---

## シナリオフロー

### 1. オーナー登録・認証
**ページ**: `/owner/auth`

**操作**:
1. オーナー登録フォームにアクセス
2. メールアドレス入力: `owner@example.com`
3. パスワード入力: `SecurePass123!`
4. ショップ名入力: `テストショップ`
5. 「登録」ボタンクリック
6. 登録成功を確認

**期待結果**:
- 登録成功メッセージ表示
- 自動的にオーナーダッシュボードへリダイレクト

---

### 2. ショップ情報登録
**ページ**: `/owner/shop/register`

**操作**:
1. ショップ登録ページにアクセス
2. ショップ名入力: `テストショップ`
3. ショップ説明入力: `テスト用のショップです`
4. カテゴリ選択: `Electronics`
5. 住所情報入力:
   - 郵便番号: `100-0001`
   - 都道府県: `東京都`
   - 市区町村: `千代田区`
   - 番地: `1-1-1`
6. 営業時間設定:
   - 平日: `9:00 - 18:00`
   - 土日: `10:00 - 17:00`
7. 「登録」ボタンクリック

**期待結果**:
- ショップ登録成功メッセージ
- ダッシュボードへリダイレクト
- ショップ情報が保存される

---

### 3. オーナーダッシュボード確認
**ページ**: `/owner/dashboard`

**操作**:
1. ダッシュボードにアクセス
2. 統計情報を確認:
   - 登録商品数
   - 総売上
   - 今月の注文数
   - 在庫アラート
3. 最近の注文一覧を確認
4. グラフ・チャートを確認（売上推移等）

**期待結果**:
- ダッシュボードが正常に表示される
- 統計情報が取得・表示される（gRPC通信成功）
- グラフが描画される

---

### 4. 商品登録（1つ目）
**ページ**: `/owner/products/new`

**操作**:
1. 「商品追加」ボタンクリック
2. 商品情報入力:
   - 商品名: `ワイヤレスイヤホン Pro`
   - 説明: `高音質ワイヤレスイヤホン`
   - カテゴリ: `Electronics`
   - 価格: `12,800`
   - 在庫数: `50`
   - SKU: `WH-PRO-001`
3. 商品画像アップロード（オプション）
4. バリエーション設定:
   - カラー: `黒、白、赤`
   - サイズ: なし
5. 「保存」ボタンクリック

**期待結果**:
- 商品登録成功メッセージ
- 商品管理一覧ページへリダイレクト
- 新規商品が一覧に表示される

---

### 5. 商品登録（2つ目）
**ページ**: `/owner/products/new`

**操作**:
1. 再度「商品追加」ボタンクリック
2. 商品情報入力:
   - 商品名: `Bluetoothスピーカー`
   - 説明: `防水対応ポータブルスピーカー`
   - カテゴリ: `Electronics`
   - 価格: `8,500`
   - 在庫数: `30`
   - SKU: `BT-SPK-001`
3. 「保存」ボタンクリック

**期待結果**:
- 商品登録成功
- 商品一覧に2つの商品が表示される

---

### 6. 商品管理一覧確認
**ページ**: `/owner/products`

**操作**:
1. 商品管理一覧ページにアクセス
2. 登録した2つの商品を確認:
   - ワイヤレスイヤホン Pro
   - Bluetoothスピーカー
3. 各商品の情報を確認:
   - 在庫数
   - 価格
   - ステータス（公開/非公開）
4. 検索機能を試す:
   - 「イヤホン」で検索
   - フィルタ機能を試す（カテゴリ、価格帯等）

**期待結果**:
- 2つの商品が一覧に表示される
- 各商品の情報が正しく表示される
- 検索・フィルタ機能が動作する

---

### 7. 商品編集
**ページ**: `/owner/products/:id/edit`

**操作**:
1. 「ワイヤレスイヤホン Pro」の「編集」ボタンクリック
2. 商品情報を修正:
   - 価格を `12,800` → `11,800` に変更
   - 説明を更新: `高音質ワイヤレスイヤホン【期間限定セール】`
   - 在庫数を `50` → `45` に変更
3. 「更新」ボタンクリック

**期待結果**:
- 商品更新成功メッセージ
- 商品一覧に戻る
- 更新された情報が反映される

---

### 8. 商品の公開/非公開切り替え
**ページ**: `/owner/products`

**操作**:
1. 「Bluetoothスピーカー」の公開ステータストグル
2. 「非公開」に設定
3. 確認ダイアログで「OK」
4. 再度トグルして「公開」に戻す

**期待結果**:
- ステータスが即座に切り替わる
- 非公開時は顧客側の商品一覧に表示されない
- 公開時は顧客側の商品一覧に表示される

---

### 9. 在庫管理
**ページ**: `/owner/products`

**操作**:
1. 各商品の在庫数を確認
2. 在庫アラート（在庫数が少ない商品）を確認
3. 在庫数を一括更新:
   - ワイヤレスイヤホン Pro: `45` → `100`
   - Bluetoothスピーカー: `30` → `50`

**期待結果**:
- 在庫数が即座に更新される
- 在庫アラートが適切に表示/非表示される
- ダッシュボードの在庫統計が更新される

---

### 10. 注文管理確認（オプション）
**ページ**: `/owner/orders` (実装済みの場合)

**操作**:
1. 注文管理ページにアクセス
2. 注文一覧を確認:
   - 注文日時
   - 顧客名
   - 商品名・数量
   - 注文ステータス
   - 合計金額
3. 注文詳細を確認
4. 注文ステータスを更新:
   - 「処理中」→「発送済み」

**期待結果**:
- 注文一覧が正常に表示される
- 注文詳細が確認できる
- ステータス更新が成功する
- 顧客に通知が送信される

---

### 11. 設定画面巡回
**ページ**: 各種設定ページ

**操作**:
1. プロフィール設定ページにアクセス
2. ショップ設定ページにアクセス
3. 通知設定ページにアクセス
4. 決済設定ページにアクセス
5. 配送設定ページにアクセス

**期待結果**:
- 各設定ページが正常に表示される
- 設定内容が保存・取得される
- エラーが発生しない

---

### 12. ログアウト
**ページ**: 任意のページ

**操作**:
1. ヘッダーのユーザーメニューをクリック
2. 「ログアウト」を選択
3. 確認ダイアログで「OK」

**期待結果**:
- ログアウト成功メッセージ
- ログインページへリダイレクト
- セッションがクリアされる

---

## テスト観点

### 機能要件
- [x] オーナー登録・ログインが正常に動作する
- [x] ショップ情報の登録・更新ができる
- [x] 商品の登録・編集・削除ができる
- [x] 在庫管理が正常に動作する
- [x] 注文管理が正常に動作する
- [x] 各種設定が保存・取得される

### 非機能要件
- [ ] 各画面の読み込み速度（3秒以内）
- [ ] gRPC通信が正常に動作する
- [ ] エラーハンドリングが適切に動作する
- [ ] フォームバリデーションが動作する
- [ ] レスポンシブデザインが適用される

### セキュリティ
- [ ] 認証なしでは管理画面にアクセスできない
- [ ] CSRF保護が有効
- [ ] XSS対策が有効
- [ ] SQLインジェクション対策が有効
