# 通知サービス要件定義

## サービス概要

通知サービスは、メール通知、プッシュ通知などを担当します。

**主な責務**:
- メール通知
- プッシュ通知
- 通知テンプレート管理
- 通知履歴管理
- 通知設定管理

## 機能要件

### 1. メール通知

#### 1.1 ユーザー登録関連
- **会員登録確認メール**:
  - 宛先: 登録メールアドレス
  - 内容: メール認証リンク
  - トリガー: `user.registered` イベント
- **メール認証完了通知**:
  - 宛先: 登録メールアドレス
  - 内容: 認証完了メッセージ
  - トリガー: `user.email_verified` イベント

#### 1.2 注文関連
- **注文確認メール**:
  - 宛先: 注文者メールアドレス
  - 内容: 注文番号、注文内容、配送先、金額
  - トリガー: `order.confirmed` イベント
- **発送通知メール**:
  - 宛先: 注文者メールアドレス
  - 内容: 配送伝票番号、配送業者、配送追跡URL
  - トリガー: `shipping.dispatched` イベント
- **配送完了メール**:
  - 宛先: 注文者メールアドレス
  - 内容: 配送完了メッセージ、レビュー依頼
  - トリガー: `shipping.delivered` イベント
- **注文キャンセル通知**:
  - 宛先: 注文者メールアドレス
  - 内容: キャンセル理由、返金情報
  - トリガー: `order.cancelled` イベント

#### 1.3 決済関連
- **決済完了メール**:
  - 宛先: 注文者メールアドレス
  - 内容: 決済金額、決済方法、領収書
  - トリガー: `payment.completed` イベント
- **決済失敗メール**:
  - 宛先: 注文者メールアドレス
  - 内容: 失敗理由、再試行方法
  - トリガー: `payment.failed` イベント
- **返金完了メール**:
  - 宛先: 注文者メールアドレス
  - 内容: 返金金額、返金方法
  - トリガー: `refund.completed` イベント

#### 1.4 ショップ関連
- **ショップ承認通知**:
  - 宛先: ショップ運営者メールアドレス
  - 内容: 承認メッセージ、次のステップ
  - トリガー: `shop.approved` イベント
- **ショップ却下通知**:
  - 宛先: ショップ運営者メールアドレス
  - 内容: 却下理由、再申請方法
  - トリガー: `shop.rejected` イベント
- **在庫アラートメール**:
  - 宛先: ショップ運営者メールアドレス
  - 内容: 在庫が少ない商品一覧
  - トリガー: `inventory.low` イベント
- **在庫切れ通知**:
  - 宛先: ショップ運営者メールアドレス
  - 内容: 在庫切れ商品名
  - トリガー: `inventory.out_of_stock` イベント

#### 1.5 チャット関連
- **新着メッセージ通知**:
  - 宛先: 受信者メールアドレス（オフライン時のみ）
  - 内容: 送信者名、メッセージプレビュー
  - トリガー: `chat.message.sent` イベント（受信者がオフライン時）

#### 1.6 その他
- **パスワードリセットメール**:
  - 宛先: ユーザーメールアドレス
  - 内容: パスワードリセットリンク
  - トリガー: Auth Serviceから直接送信依頼
- **在庫復活通知**:
  - 宛先: お気に入り登録ユーザー
  - 内容: 商品名、商品URL
  - トリガー: `inventory.stock_restored` イベント

---

### 2. プッシュ通知

#### 2.1 注文ステータス更新
- 注文ステータスが変更された際に通知
- タイトル: 「注文状況が更新されました」
- 内容: 新しいステータス

#### 2.2 在庫復活通知
- お気に入り商品の在庫が復活した際に通知
- タイトル: 「お気に入り商品が入荷しました」
- 内容: 商品名

#### 2.3 セール・キャンペーン通知
- セール・キャンペーン開始時に通知
- タイトル: キャンペーン名
- 内容: キャンペーン詳細

#### 2.4 チャットメッセージ通知
- 新着メッセージ受信時に通知（オフライン時）
- タイトル: 送信者名
- 内容: メッセージプレビュー

---

### 3. 通知テンプレート管理

#### 3.1 テンプレート種別
- メール件名テンプレート
- メール本文テンプレート（HTML/TEXT）
- プッシュ通知タイトルテンプレート
- プッシュ通知本文テンプレート

#### 3.2 テンプレート変数
- `{{user_name}}`: ユーザー名
- `{{order_number}}`: 注文番号
- `{{tracking_number}}`: 配送伝票番号
- `{{shop_name}}`: ショップ名
- `{{product_name}}`: 商品名
- `{{amount}}`: 金額
- `{{url}}`: リンクURL

#### 3.3 テンプレート管理
- 管理者がテンプレートを編集可能
- バージョン管理
- プレビュー機能
- テスト送信機能

---

### 4. 通知履歴管理

#### 4.1 通知履歴記録
- すべての通知を記録:
  - 通知種別
  - 宛先
  - 送信日時
  - 送信ステータス（成功/失敗）
  - エラー内容（失敗時）

#### 4.2 通知履歴照会
- ユーザーごとの通知履歴
- フィルター:
  - 通知種別
  - 期間
  - ステータス
- ページネーション: 50件/ページ

#### 4.3 再送機能
- 送信失敗した通知の再送
- 手動再送・自動再送（リトライ）

---

### 5. 通知設定管理

#### 5.1 通知設定
- ユーザーごとの通知ON/OFF設定:
  - メール通知: 注文関連、ショップ関連、チャット関連
  - プッシュ通知: 注文関連、在庫復活、キャンペーン、チャット関連

#### 5.2 通知頻度設定
- **即座に通知**: デフォルト
- **1日1回まとめて通知**: 朝9時に前日分をまとめて送信
- **通知しない**

#### 5.3 静音時間設定
- 通知を受け取らない時間帯を設定
- 例: 22:00-08:00は通知しない

---

### 6. メール送信機能

#### 6.1 SMTPサーバー連携
- SMTP経由でメール送信
- TLS暗号化対応
- 送信失敗時のリトライ（最大3回、Exponential Backoff）

#### 6.2 メール送信プロバイダー連携
- SendGrid / AWS SES / Mailgun のいずれか
- APIキー管理
- 送信レート制限

#### 6.3 メール配信ステータス追跡
- 送信成功/失敗
- バウンスメール検知
- 開封率追跡（オプション）

---

### 7. プッシュ通知機能

#### 7.1 デバイストークン管理
- iOS/Android デバイストークン登録
- デバイストークンの無効化検知
- 複数デバイス対応

#### 7.2 プッシュ通知送信
- Firebase Cloud Messaging (FCM) 連携
- APNs (Apple Push Notification service) 連携
- 送信失敗時のリトライ
