# ショップサービス要件定義

## サービス概要

ショップサービスは、ショップ運営者による店舗および商品の管理を担当します。

**主な責務**:
- ショップ情報管理
- 商品管理（CRUD）
- 注文管理
- 売上レポート管理

## 機能要件

### 1. ショップ管理

#### 1.1 ショップ登録
- ショップ運営者が新規ショップを登録
- 必須情報:
  - ショップ名
  - ショップ説明
  - ショップロゴ画像
  - 運営者情報（氏名、電話番号）
  - 営業時間
  - 返品ポリシー
- 管理者承認が必要（承認されるまで公開不可）

#### 1.2 ショップ情報編集
- ショップ名、説明、ロゴ画像の更新
- 営業時間、返品ポリシーの更新
- 再審査が必要な変更の場合は管理者承認が必要

#### 1.3 ショップ公開/非公開設定
- ショップ運営者がショップの公開/非公開を切り替え可能
- 非公開時は商品も非表示

#### 1.4 ショップカテゴリー設定
- ショップのカテゴリー（アパレル、食品、家電など）を設定
- 複数カテゴリーの選択可能

---

### 2. 商品管理

#### 2.1 商品登録
- 必須情報:
  - 商品名
  - 商品説明
  - 価格
  - 商品カテゴリー
  - 商品画像（最大5枚）
  - 在庫数
- オプション情報:
  - 商品タグ
  - 商品重量
  - 商品サイズ
  - JANコード

#### 2.2 商品編集
- 商品情報の更新
- 商品画像の追加/削除/順序変更

#### 2.3 商品削除
- 論理削除（データベースには残す）
- 削除済み商品は一覧に表示されない
- 過去の注文履歴には残る

#### 2.4 商品画像管理
- 画像アップロード: 最大5枚まで
- 対応形式: JPEG, PNG, WEBP
- 最大ファイルサイズ: 5MB/枚
- MinIO/S3に保存
- サムネイル自動生成（200x200, 400x400, 800x800）

#### 2.5 商品公開/非公開設定
- 商品の公開/非公開を切り替え
- 非公開商品は検索・一覧に表示されない

#### 2.6 商品バリエーション管理
- サイズ、色などの属性を設定
- バリエーションごとに:
  - 価格
  - 在庫数
  - SKU
- バリエーションごとに個別管理

---

### 3. 注文管理

#### 3.1 受注一覧表示
- ショップに対する注文一覧を表示
- フィルター機能:
  - 注文ステータス
  - 注文日範囲
  - 顧客名
  - 商品名
- ソート機能:
  - 注文日（昇順/降順）
  - 合計金額（昇順/降順）

#### 3.2 注文詳細表示
- 注文情報の詳細表示:
  - 顧客情報
  - 注文商品一覧
  - 配送先住所
  - 支払い方法
  - 合計金額
  - 注文ステータス

#### 3.3 注文ステータス更新
- ステータス遷移:
  1. **注文受付** → 2. **準備中** → 3. **発送済み** → 4. **配送完了**
  - キャンセル: どのステータスからでも可能（発送前まで）
- ステータス更新時にイベント発行（通知サービスへ）

#### 3.4 配送伝票番号登録
- 発送済みステータス時に配送伝票番号を登録
- 配送業者の選択（ヤマト運輸、佐川急便、日本郵便など）

---

### 4. 売上管理

#### 4.1 売上レポート表示
- **日別売上**:
  - 指定期間の日別売上グラフ
  - 売上合計、注文件数、平均単価
- **月別売上**:
  - 月別売上推移グラフ
  - 前年比較
- **商品別売上**:
  - 商品ごとの売上ランキング
  - 売上金額、販売個数

#### 4.2 売上データエクスポート
- CSV形式でエクスポート
- エクスポート項目:
  - 注文日時
  - 注文番号
  - 商品名
  - 数量
  - 単価
  - 合計金額
  - 注文ステータス
