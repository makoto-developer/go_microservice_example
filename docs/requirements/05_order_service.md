# 注文サービス要件定義

## サービス概要

注文サービスは、注文の作成、ステータス管理、注文履歴、キャンセル処理などを担当します。

**主な責務**:
- 注文作成
- 注文ステータス管理
- 注文履歴管理
- 注文キャンセル処理
- 注文検索・統計

## 機能要件

### 1. 注文作成

#### 1.1 注文情報
- 注文者情報:
  - ユーザーID
  - メールアドレス
- 配送先情報:
  - 配送先住所（Customer Serviceから取得）
  - 受取人氏名
  - 受取人電話番号
- 注文商品情報:
  - 商品ID
  - バリエーションID（オプション）
  - 商品名（注文時点のスナップショット）
  - 単価（注文時点のスナップショット）
  - 数量
  - 小計
- 支払い情報:
  - 支払い方法（クレジットカード、代引き）
  - クレジットカードID（クレジットカード決済の場合）
- 配送情報:
  - 配送方法
  - 配送料
- 金額情報:
  - 商品合計
  - 配送料
  - 合計金額

#### 1.2 注文作成フロー
1. カート内容の取得（Customer Service）
2. 在庫引き当て（Inventory Service）
3. 注文レコード作成
4. 決済処理開始（Payment Service）
5. 決済成功時:
   - 注文ステータスを「注文受付」に更新
   - 在庫確定（Inventory Service）
   - カートクリア（Customer Service）
   - 注文確認メール送信（Notification Service）
6. 決済失敗時:
   - 注文ステータスを「決済失敗」に更新
   - 在庫リリース（Inventory Service）
   - エラー通知（Notification Service）

#### 1.3 注文番号
- フォーマット: `ORD-YYYYMMDD-XXXXXXXX`
  - 例: `ORD-20240101-A1B2C3D4`
- 注文日 + ランダム文字列（8桁）
- ユニーク制約

---

### 2. 注文ステータス管理

#### 2.1 ステータス定義
- **注文作成中** (`pending`): 注文作成処理中
- **決済処理中** (`payment_processing`): 決済処理中
- **決済失敗** (`payment_failed`): 決済失敗
- **注文受付** (`confirmed`): 注文確定、ショップ側の処理待ち
- **準備中** (`preparing`): ショップ側で商品準備中
- **発送済み** (`shipped`): 発送完了
- **配送完了** (`delivered`): 配送完了
- **キャンセル** (`cancelled`): キャンセル済み

#### 2.2 ステータス遷移
```
注文作成中 → 決済処理中 → 注文受付 → 準備中 → 発送済み → 配送完了
           ↓               ↓       ↓
        決済失敗      キャンセル  キャンセル
```

#### 2.3 ステータス更新
- ショップ運営者による更新: `準備中` → `発送済み`
- システムによる自動更新: `決済処理中` → `注文受付`
- 配送業者連携による更新: `発送済み` → `配送完了`
- ステータス更新時にイベント発行

---

### 3. 注文キャンセル

#### 3.1 キャンセル可能条件
- キャンセル可能ステータス:
  - 注文受付
  - 準備中
- キャンセル不可ステータス:
  - 発送済み
  - 配送完了
  - キャンセル済み

#### 3.2 キャンセル処理
1. キャンセル可能かチェック
2. 注文ステータスを「キャンセル」に更新
3. 在庫リリース（Inventory Service）
4. 決済済みの場合は返金処理（Payment Service）
5. キャンセル通知メール送信（Notification Service）

#### 3.3 キャンセル理由
- カスタマーによるキャンセル:
  - 不要になった
  - 間違えて注文した
  - 配送日時が合わない
  - その他
- ショップ運営者によるキャンセル:
  - 在庫切れ
  - 商品不良
  - その他

---

### 4. 注文履歴・検索

#### 4.1 注文一覧表示
- カスタマー側:
  - 自分の注文のみ表示
  - フィルター: ステータス、期間
  - ソート: 注文日（新しい順/古い順）
  - ページネーション: 20件/ページ
- ショップ運営者側:
  - 自分のショップへの注文のみ表示
  - フィルター: ステータス、期間、顧客名
  - ソート: 注文日、合計金額
  - ページネーション: 50件/ページ

#### 4.2 注文詳細表示
- 注文番号
- 注文日時
- 注文ステータス
- 注文者情報
- 配送先情報
- 注文商品一覧
- 金額内訳
- 支払い方法
- 配送方法
- 配送伝票番号
- ステータス履歴（タイムライン表示）

#### 4.3 注文検索
- 検索条件:
  - 注文番号
  - 顧客名
  - メールアドレス
  - 商品名
  - 期間
  - ステータス
  - 金額範囲

---

### 5. 注文統計

#### 5.1 統計情報
- 総注文数
- 総売上金額
- 平均注文金額
- ステータス別注文数
- 期間別注文推移（日別、週別、月別）

#### 5.2 レポート
- 売上レポート（日別、月別）
- 商品別売上ランキング
- キャンセル率
- CSV/PDFエクスポート
